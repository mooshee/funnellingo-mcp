# Release notes

## 0.2.0 — October 28, 2026

This first consumer integration package provides connection settings and a skill
for website translation. It includes instructions for inspecting existing wording,
preparing changes, reviewing release plans, and checking publication results.

The package uses the current FunnelLingo branding and links to account access,
setup information, support and policies. Account access includes password
recovery on the website.

Consumer skills, documentation and connector configurations use MIT-0. Brand
assets retain their separate rights; the private application and existing
account adapters are excluded.

An eligible account and supported OAuth connection are required. Approved wording,
spending limits and publication decisions keep their existing protections.
Connection support and publication status are verified separately for each host.

See [setup instructions](https://funnellingo.com/agents) and the package README
for account requirements and connection limits. Host-specific settings are
provided for installation; they do not establish a working OAuth connection.

## 0.1.0 — October 28, 2026

Added public connection information and directory metadata for FunnelLingo's
remote MCP service. Follow the [setup guide](https://funnellingo.com/agents) to
connect an eligible business-account installation.

Start with read access to inspect your website. Drafting, setup and publishing
require their matching permissions. Approved wording, spending limits and
publication decisions keep their existing protections.

The host must support MCP `2026-07-28` and HTTPS Client ID Metadata Documents.
Connection support must be verified in each host. This release contains no
installable plugin or skill archives.
