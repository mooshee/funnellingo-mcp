# FunnelLingo

Translate website pages, review changes, and publish approved wording with
permissions you choose.

[Website](https://funnellingo.com) · [Setup](https://funnellingo.com/agents) ·
[Support](https://funnellingo.com/support)

## Connect

Follow the [agent setup guide](https://funnellingo.com/agents) using an active
FunnelLingo installation in your business account. Administrator access is
required. Review the plan and price before subscribing.

Add `https://api.funnellingo.com/agent/mcp` through your host's OAuth connection
flow. The host must support MCP `2026-07-28` and HTTPS Client ID Metadata
Documents. Start with read access for an inspection. Drafting, setup and
publishing require their corresponding permissions; reconnect and refresh the
tool catalog when those permissions change.

Connections are short-lived. Reconnect when access expires, and keep passwords
and access tokens out of chat. Human-approved wording, spending limits and
publication approval keep their existing protections.
